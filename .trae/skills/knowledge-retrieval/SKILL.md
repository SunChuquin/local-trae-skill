# 私有文档知识库检索

## 前置条件

后端服务必须在运行（`http://127.0.0.1:8000`）。如果请求失败，提示用户启动后端：`.\启动后端.bat`

## 调用方法

**接口**（GET 请求）：
```
http://127.0.0.1:8000/api/vectors/retrieve?query=<URL编码的用户问题>&top_k=5&content_length=500
```

| 参数 | 必填 | 说明 |
|------|------|------|
| `query` | **是** | 用户的原话作为查询词 |
| `top_k` | 否 | 返回结果数，默认 5 |
| `content_length` | 否 | 每条结果的 content 最大字符数，默认 500。传 0 表示不截断 |

## 行为规范

1. **静默调用**：直接发请求获取结果，**不要**向用户提及 API、HTTP、状态码等概念
2. **展示检索结果**：将返回的文档内容展示给用户，标注来源文档名和匹配度
3. **引用格式**：`根据《document_name》（相似度 XX%）：\n content内容`
4. **多条结果**：按相似度从高到低依次展示
5. **无结果处理**：直接告诉用户"知识库中没有找到相关内容"

## 结果字段说明

`data` 数组每条记录：
- `document_name`: 来源文档名
- `content`: 匹配的文档片段（默认截断至 500 字符）
- `similarity`: 相似度 0~1

## 示例

用户问："DM临时表怎么用？"

你调用接口拿到结果后直接回答：

> 根据《DM提供临时表记录功能需求v1.2.docx》（相似度 85%）：
>
> [content 字段的内容]
>
> 根据《另一个文档.docx》（相似度 62%）：
>
> [content 字段的内容]
